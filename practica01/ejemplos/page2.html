HTML (HyperText Markup Language)

El Estándar Fundamental de Internet

HTML es el lenguaje base sobre el que se construye toda la World Wide Web. Administrado por el consorcio internacional W3C y el grupo WHATWG, HTML define la estructura sintáctica y semántica de las páginas mediante el uso de etiquetas delimitadas por corchetes angulares.

Pilares de HTML5

  • Semántica Estructural: Introducción de elementos nativos como header, nav, section y article que mejoran la accesibilidad y el posicionamiento SEO.
  • Soporte Multimedia Nativo: Integración directa de audio y video sin necesidad de complementos externos.
  • Compatibilidad Universal: Interpretación uniforme en todos los navegadores modernos (Chrome, Firefox, Safari, Edge).

Ficha Técnica

  • Versión estándar actual: HTML5 Living Standard.
  • MIME Type: text/html.
  • Organización rectora: W3C / WHATWG.
